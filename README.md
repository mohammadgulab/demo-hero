# Kestrex Armorworks (demo)

A cinematic demo website for a fictional armored suit lab: boot up intro, HUD overlays, a glowing core and a suit that assembles as you scroll. All visuals are drawn in code (SVG, CSS and canvas).

Kestrex Armorworks is fictional and not connected to any real company, film or character.

Live: https://mohammadgulab.github.io/demo-hero/
